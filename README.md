# 小故囊 · 成语故事

一个给自家孩子用的成语典故小工具：手机优先、微信浮窗/浏览器书签点开即用，不是 App、不做后端、不部署服务器。
每一则都是白话故事，大人念着不幼稚、孩子听得懂；点开还能看「出自哪部古籍的原文」。

## 功能一览

- **随手翻 / 随机读**：打开随机给一则，可「换一则」「上一则 / 下一则」。
- **目录抽屉**：点右上角「目录」可按 **拼音**（A–Z）或 **出处大类**（经 / 史 / 子 / 集 / 笔记佛典）浏览全部 100 则，点哪条跳哪条。
- **出处标签**：每张卡片标注该则出自五大类中的哪一部（如「子部」「史部」）。
- **原文折叠**：点「出自古籍原文」展开该则的公版文言原文与出处。
- **寓意可隐藏**：「讲讲道理」一键展开/收起一句道理，方便先让孩子猜。
- **搜索**：按成语或拼音检索。

## 内容规模

- **100 则**成语典故，每条含：成语、拼音、白话故事、典故出处（《史记》《战国策》《庄子》《论语》《列子》等）、古籍关键原文、一句道理。
- 故事篇幅 **约 150–320 字**（详见下方「关于篇幅」）。

## 技术栈

- 单文件 `index.html`（Vue 3 global build + 自写 CSS，CDN 走 jsdelivr）
- `stories.json`（100 则数据）
- PWA（`manifest.webmanifest` + `sw.js`）

## 改动铁律（务必遵守）

1. **每次改动必须同步升 `APP_VERSION`**（`index.html` 常量 + `sw.js` 的 `APP_VERSION`）。当前版本 **v2**。这是绕过手机微信缓存的唯一手段。
2. **微信内置浏览器禁用 Service Worker**（检测 `MicroMessenger` UA 后不注册）。微信对 SW 支持差、缓存陷阱多。
3. **隐藏元素用 `v-if` 销毁节点**，不要用 `visibility:hidden`。
4. 数据源以公版古籍原文 + 自写改写为基准；教育部《成语典》(CC BY-ND) 经主人授权可参考使用，但**仍禁止**从其他无 License / 来源不明仓库扒取现成故事文本。

## 关于篇幅

当前故事为「典故丰俭浮动」写法：有真故事的（如卧薪尝胆）写足，典故单薄的就短说，不注水。
**已与主人确认：保持当前篇幅**（约 150–320 字，中位约 147 字），不统一拉到 300–400 字——强行拉长会牺牲这版的准确与流畅。

## 命名

正式品牌名 **小故囊**（故=故事，呼应「成语故事」初心；「小+囊」为手机里随手取用的小口袋，与小诗囊同族）。由 AI 依主人「取一个合适的名字」的授权定名，如需更名仅改 `index.html` 标题/`manifest`/`README` 三处 + 升 `APP_VERSION` 即可。
