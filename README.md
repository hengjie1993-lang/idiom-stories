# 成语小书 · 成语典故随手读

> 纯前端、手机优先、无后端的成语典故阅读小工具。新中式雅致风格，适合亲子共读，也适合独自翻阅。
> 随手一翻就是一则白话故事，会讲来历、会点出典故原文、会讲个道理。

- 线上地址：<https://hengjie1993-lang.github.io/idiom-stories/>
- 源码仓库：`hengjie1993-lang/idiom-stories`（GitHub Pages 托管，无服务器）
- 当前版本：**v18**

## 二、功能全景（v18）

**随手翻读**
- 打开随机给一则；支持「换一则」「上一则 / 下一则」。
- 手机左右滑、桌面方向键均可切篇。

**发现与检索**
- 顶部 **14 主题标签栏**（动物 / 人物 / 战争 / 自然 / 学习 / 品德 / 友谊 / 励志 / 智慧 / 历史 / 数字 / 颜色 / 身体 / 言语 / 收藏），点选即筛选。
- **搜索**支持三种输入：成语原文 / 拼音全拼 / 首字母（如 `hldj` → 画龙点睛）。
- **目录抽屉**三模式：按拼音（A–Z）、按出处大类（经/史/子/集/笔记佛典）、按主题（`tags` 首标签）。

**阅读沉浸**
- 阅读控件：字号（小/中/大）、拼音显隐、**原文显隐（默认隐藏）**、夜读模式、收藏（`localStorage`）、分享卡。
- 正文排版：每段**首行缩进 2em** + 两端对齐；结尾「这就是「成语」——释义」自动抽成带朱砂左边线的**「点睛」框**，与白话叙述、讲道理分层。

**分享卡**
- `<canvas>` 现场绘制 1080×1440 卡片：印章品牌 + 成语 + 拼音 + 主题标签 + 小故事前 100 字（超出省略号）+ 指向该则的二维码 +「复制链接」按钮。
- 二维码内容为 `?q=成语` 深链，**扫码 / 点链直达这则**；「复制链接」把深链复制到剪贴板，可在微信内粘贴发送给好友；保存图片靠长按。

## 三、技术架构

```
idiom-stories/
├── index.html            # 单文件 Vue3 应用（Vue3 global build CDN + 自写 CSS）
├── stories.json          # 1558 则数据（id/word/pinyin/story/source/quote/moral/tags）
├── sw.js                 # Service Worker：透明穿透，不缓存，激活即强刷
├── manifest.webmanifest  # PWA 清单
├── build_tags.py         # 给每条成语生成 tags（主题标签）
├── build_stories.py      # 早期 20 则小样构建脚本（保留作文风参考）
├── HANDOFF.md            # 技术交接文档（接手即改必读）
├── README.md             # 本文件
└── LICENSE               # MIT
```

**几个关键实现点**
- `APP_VERSION` 常量在 `index.html` 与 `sw.js` **两处同步**。改任何前端文件都必须升它 + 升 `stories.json` 的 `?v=N` 戳，这是绕过手机微信缓存的唯一手段。
- `sw.js` 透明穿透（不缓存任何资源）+ 微信 UA 下禁用 SW，彻底根治「手机端困在旧版」。
- 隐藏元素一律用 `v-if` 销毁节点，不用 `visibility:hidden`（避免带固定高度元素留白）。
- 分享卡二维码走 jsDelivr ESM（`qrcode@1.5.3/+esm`），深链 `?q=成语`；`load()` 读 URL 的 `q` 参数直接定位该则。

## 四、数据来源与授权（红线）

- **故事文本分两层**：最早 100 则由我依据《诗经》《史记》《战国策》《庄子》《论语》等公版古籍原文独立自写；后续扩充的 1400+ 则直接采用**台湾教育部《成语典》白话典故（典故說明）**——该典授权为 CC BY-ND 3.0 TW（原「禁止改作」），**经主人明确授权已放宽**，可直接使用。
- 教育部《成语典》白话典故偏「词典体」（字源拆解、多出处罗列），不适合直接读给孩子听，已全部改写成前 100 则的亲子朗读风格并达标（正文可读性评分全部 <6）。
- 古籍原文（如《史记》《庄子》）作者去世逾两千年，本属公有领域。
- **清洗改写流水线**在 `_cydata/`（已 gitignore，非发布内容）：`expand_stories.py` 扩充、`rewrite_with_llm.py` 改写、`score_dictionary_like.py` 评分优先改写最绕口条目等。
- **`build_tags.py` 打标法**（已沉淀为可复用经验）：高频成语人工校准表（约 100 条）+ 关键词自动打标（**仅在成语四字本身匹配**，避免正文高频字噪声）+ 低频多字短语在正文精确匹配扩覆盖；先备份再落盘，幂等可重复跑。

> ⚠️ 授权红线：禁止从其他无 License / 来源不明仓库扒取现成故事文本。评估数据集先算全量分布再看样本，抽样偏差会严重误导。

## 五、改动铁律（接手必读）

| # | 铁律 | 不遵守的后果 |
|---|------|------|
| 1 | 改 `index.html`/`stories.json`/`sw.js` 必须同步升 `APP_VERSION`（`index.html` 常量 + `sw.js` 的 `APP_VERSION`） | 手机微信端长期困在旧版 |
| 2 | 微信内置浏览器禁用 SW（`MicroMessenger` UA 判定不注册） | 微信对 SW 支持差，缓存陷阱多 |
| 3 | 隐藏元素用 `v-if` 销毁节点，不要 `visibility:hidden` | 带固定高度元素留白 |
| 4 | 白话故事以公版古籍原文自写为基准；教育部《成语典》(CC BY-ND) 经授权可参考/改写，**禁止**从无 License 仓库扒取 | 版权风险 |

## 七、本地运行

```bash
cd idiom-stories
python -m http.server 8231
# 电脑打开 http://localhost:8231
# 手机（同 WiFi）打开 http://<电脑局域网IP>:8231
```

重建 / 刷新主题标签：

```bash
python build_tags.py      # 给 stories.json 每条生成/更新 tags（先自动备份，幂等）
```
